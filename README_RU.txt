Auto Drop Item — Fabric 1.21.11

Важно: это исходники с автоматической сборкой через GitHub Actions, а не готовый .jar. В текущей среде не удалось скачать зависимости Fabric/Gradle, поэтому я не могу честно приложить проверенный .jar.

Как получить JAR без установки Java на свой компьютер:
1. Создай новый репозиторий на https://github.com/new (можно Public или Private).
2. Распакуй этот архив и загрузи ВСЁ его содержимое в корень репозитория, включая скрытую папку .github.
3. Открой вкладку Actions в репозитории и разреши GitHub Actions, если GitHub попросит.
4. Если workflow не стартовал после загрузки файлов: Actions → Build Auto Drop Item → Run workflow.
5. Открой завершившийся запуск и скачай артефакт auto-drop-item-fabric-1.21.11.
6. Распакуй артефакт и положи основной auto-drop-item-1.0.0.jar в .minecraft/mods. Не используй файл с суффиксом -sources.

В игре: O — включить/выключить автосброс, P — сбросить подходящий предмет один раз.
По умолчанию предмет: minecraft:rotten_flesh. Конфиг: config/auto-drop-item.properties.

Сборка всё ещё требует успешного разрешения зависимостей в GitHub Actions. Если сборка упадёт, сохрани лог ошибки.
